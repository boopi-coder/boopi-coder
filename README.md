**Business software development** · Omsk · [boopi.ru](https://boopi.ru)

---

Небольшие самодостаточные инструменты: один файл скопировал — и оно работает.
Без облаков там, где данные могут остаться на своей машине.

*Small self-contained tools — copy one file and it runs. No cloud where the data
can just as well stay on your own machine.*
