<h3><img src="assets/thelxis-icon.png" alt="" width="32" align="center">&nbsp;<a href="https://github.com/boopi-coder/thelxis">Thelxis</a></h3>

**Удалённый рабочий стол без серверов и аккаунтов.** Сквозное шифрование, связь «компьютер — компьютер» напрямую по WebRTC — картинка не зависает. Передача файлов и буфер обмена, подключение по коду даже через NAT оператора, обязательный индикатор «вы подключены» на экране и подписанные OTA-обновления.<br>
*Serverless, end-to-end encrypted remote desktop. PC-to-PC over WebRTC, no servers, no accounts. File transfer and clipboard, connect-by-code through carrier NAT, a mandatory on-screen “connected” badge and signed OTA updates.*

<h3><img src="assets/auris-icon.png" alt="" width="32" align="center">&nbsp;<a href="https://github.com/boopi-coder/auris-whisper">Auris Whisper</a></h3>

**Офлайн-расшифровка речи.** Перетащите файл или надиктуйте — получите чистый `.txt`. Русские модели GigaAM v3 и T-One, Whisper для ~30 языков, разделение по говорящим, ускорение на GPU (Metal / Vulkan) и автообновления. Ничего не уходит с компьютера.<br>
*Offline speech-to-text. Drop a file or dictate and get a clean `.txt`. Russian GigaAM v3 / T-One models, Whisper for ~30 languages, speaker separation, GPU acceleration (Metal / Vulkan), auto-updates. Nothing leaves your computer.*
